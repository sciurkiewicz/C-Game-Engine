# Obrazy kart narracyjnych

Umieść tutaj własne obrazy PNG, JPG/JPEG, BMP lub TGA. Następnie w [intro.json](../intro.json) wpisz np. `"Image": "images/las.png"`. Obraz pojawi się nad blokami tekstu i zachowa swoje proporcje.

`"Image": null` oznacza kartę bez obrazu. Możesz używać podfolderów, np. `images/rozdzial-1/poludnie.jpg`. Zapisz plik JSON i ponownie wybierz **Nowa gra**, aby zobaczyć zmiany.
