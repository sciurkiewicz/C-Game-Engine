# Dźwięki

Dodaj WAV, OGG lub MP3, także w podkatalogach. W edytorze wybierz **World → Sounds**, dodaj emiter i wybierz plik. Dźwięk cichnie wraz z odległością, a panorama podąża za kierunkiem kamery.

Wbudowane dźwięki fire, water i kroki są generowanymi placeholderami. Ogniska, pochodnie i pobliska woda otrzymują dźwięk automatycznie. Głośność i wyciszenie: **World → Environment**.
