# Fragmenty mapy

Narzędzie **Map fragments** zapisuje tutaj nazwane obszary do wielokrotnego użycia, np. obozy, polany i fragmenty wiosek.

**Ctrl+Shift+C** rozpoczyna zaznaczanie, **Ctrl+V** pokazuje podgląd wklejania, a **Save fragment** zapisuje zawartość do osobnego pliku JSON. W **Fragment library** wybierz **Place**, aby wstawić zapisany fragment na bieżącej lub innej mapie. Całe wklejenie można cofnąć jednym Ctrl+Z.

Format przechowuje materiały, wysokości, wodę, obiekty, NPC, skrzynie, potwory, drogi oraz elementy świata. Ścieżki grafik pozostają względne wobec biblioteki edytora; obrazy nie są duplikowane. Nowe kopie mają niezależne identyfikatory, zawartość skrzyń i połączenia lokalnych triggerów.

Szczegóły obsługi i ustawień są w [instrukcji edytora](../README.md#fragmenty-mapy).
