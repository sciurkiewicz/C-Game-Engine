# Prefabrykaty

Zaznacz obiekty, NPC, skrzynie lub potwory przez **Shift+klik**. Wybierz **World → Prefabs → Save selected group**, wpisz nazwę i zatwierdź Enterem. Plik JSON pojawi się w tym katalogu.

**Place prefab on map** pozwala wstawiać kolejne egzemplarze kliknięciem. Escape kończy wstawianie. Układ, grafiki, kolizje, drzwi, dialogi, statystyki i zawartość skrzyń są zachowane. Każde wstawienie tworzy nowe identyfikatory aktorów i przedmiotów oraz stanowi jeden krok cofania.

Cała grupa musi mieścić się na mapie. Można przenosić pliki JSON między projektami korzystającymi z tych samych grafik. Prefab jest kopiowany przy wstawieniu; późniejsza zmiana biblioteki nie zmienia już umieszczonych egzemplarzy.
